# ADR-002 — OpenAI Agents SDK como runtime futuro

Status: Accepted

## Context
Las fases futuras necesitan un runtime de agente.

## Decision
Utilizar OpenAI Agents SDK en una fase posterior.

## Alternatives
Runtime propio u otros frameworks.

## Consequences
No se instala ni implementa en Foundation; proveedores LLM serán configurables sin fallback automático V1.
