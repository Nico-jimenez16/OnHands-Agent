# ADR-004 — Controlled Autonomy: READ automático / WRITE confirmado

Status: Accepted

## Context
Las operaciones de escritura producen efectos de negocio.

## Decision
Permitir READ automático y exigir confirmación explícita para WRITE.

## Alternatives
Confirmar todo o permitir escritura autónoma.

## Consequences
Runtime futuro debe controlar y registrar confirmaciones.
