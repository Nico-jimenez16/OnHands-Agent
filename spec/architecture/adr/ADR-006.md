# ADR-006 — Microservices communicate through APIs, not foreign databases

Status: Accepted

## Context
Cada microservicio es dueño de datos y reglas.

## Decision
Consumir APIs/clientes internos; nunca DBs ajenas.

## Alternatives
Acceso directo a bases de datos externas.

## Consequences
Mantener contratos de API y límites de dominio.
