# ADR-010 — Spec-Driven Development + TDD

Status: Accepted

## Context
El desarrollo debe ser verificable y guiado por contratos.

## Decision
Seguir SPEC → DESIGN → PLAN → TESTS → IMPLEMENTATION → VALIDATION → REPORT y RED → GREEN → REFACTOR → FULL TEST SUITE.

## Alternatives
Implementar primero y documentar después.

## Consequences
Actualizar especificaciones y registrar evidencia antes de cerrar cada fase.
