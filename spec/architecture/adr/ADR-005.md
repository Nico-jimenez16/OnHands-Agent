# ADR-005 — Agent Service no administra autenticación

Status: Accepted

## Context
El ecosistema ya tiene Gateway/Auth Service.

## Decision
Delegar autenticación a Gateway/Auth Service.

## Alternatives
Duplicar autenticación en el Agent Service.

## Consequences
Despliegues posteriores deberán definir el perímetro de confianza sin implementar auth propia aquí.
