# ADR-008 — MongoDB previsto para estado propio del Agent Service

Status: Accepted

## Context
El agente futuro tendrá estado y sesiones propios.

## Decision
Prever MongoDB sólo para estado propio.

## Alternatives
Base relacional o almacenamiento sólo en memoria.

## Consequences
No conectar MongoDB en Foundation ni usarlo para acceder a datos ajenos.
