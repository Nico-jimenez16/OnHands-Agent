# Especificaciones
El workflow obligatorio es SPEC → DESIGN → PLAN → TESTS → IMPLEMENTATION → VALIDATION → REPORT.
La arquitectura transversal vive en `architecture/`; cada fase mantiene su contrato, diseño, plan, pruebas y reporte en su propia carpeta.
La Fase 0 está en `phase-00-foundation/`. Los cambios arquitectónicos requieren actualizar documentos y ADRs. Una capacidad futura requiere especificación y aprobación antes de implementarse.
